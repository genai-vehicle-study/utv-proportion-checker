UTV 比例比對工具

把你的正側視定稿疊在參考模型上，檢查比例是否合理。參考模型依 Polaris RZR XP 4 1000 原廠規格建立，乘員身高 185 cm。

範例
綠色區塊：四款市售 64 吋級四人座 UTV 的比例範圍。後輪中心、車頂、車頭與車尾應落在對應區塊內。

    參考模型依 Polaris RZR XP 4 1000（2027）原廠規格：全長 3,754、全寬 1,626、全高 1,905、軸距 2,972、離地高 368、輪胎 762 mm。比例範圍取全寬 64 吋以內的四人座車款：RZR XP 4 1000、Honda Talon 1000X-4、Can-Am Maverick Sport MAX、Polaris General XP 4 1000。UTV 沒有規定比例的法規，範圍只用於比較；六輪範圍為推估。

    載入 AI 生成的正側視圖，疊在模型側視上比對比例。步驟：① 載入圖片 ② 按「兩點對齊輪心」，依序點圖上的前輪中心與最後一個車輪中心 ③ 調整左側「輪徑」（六輪再調「雙軸間距」），讓模型輪子跟圖上的輪子重疊，畫面上的綠色區塊會依輪徑標出市售車的比例範圍 ④（選擇性）按「量通過角」，點車頭與車尾最低點 ⑤ 到「比例結果」看數值。

    1. 在 Grasshopper 放一個 Python 元件（Rhino 8 用 Python 3 Script，Rhino 7 用 GhPython），貼上腳本。
    2. 新增輸入 params_json（型別 str），接一個 Panel，把複製的 JSON 貼進 Panel。
    3. 新增輸出 body canopy wheels figure profile info。
    4. 想在 GH 裡用滑桿調：新增與參數同名的輸入（如 wheelbase、wheelCount），接 Number Slider，會覆蓋 JSON 的值。

    每次放開滑桿、切換選項或套用範例都會記一筆（時間、參數、前值、後值）。紀錄只存在這個分頁裡，重新整理就會消失，每位受試者結束後請先複製出來。
